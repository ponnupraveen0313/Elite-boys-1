# SmartVestAI Demo

This ZIP contains a Vite + React prototype matching the supplied SmartVestAI dashboard screenshot.

## Run on a computer
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by the terminal.

## Build
Run `npm run build` to create the production `dist` folder.

The included `server.ts` also contains the original AI/API backend endpoints supplied with the project. The dashboard UI in `src/` is a lightweight visual prototype and does not process real investments or payments.
